# MEMORA 后台内部检查运行说明

本说明用于已发布站点的定时任务，不包含密钥。只处理工作区所有者已经启用的内部自动化，不发消息、退款、扣款或改变网站访问范围。

1. 使用原站点 ID 获取当前站点信息。确认站点已发布、当前调用者为所有者，访问策略仍仅允许所有者；不满足时停止本次运行并报告。
2. 从原生站点信息取得服务访问方式。凭证只保留在当前运行内存，通过站点专用授权头发送到该站点，不复制到源代码、任务提示或输出。服务访问不代表真实用户身份。
3. 以服务访问向 `/api/jobs/tick` 发送 POST，JSON `{}`，并附 `x-memora-scheduled-run: 1`。浏览器用户身份不能调用此共享执行入口。不要添加或伪造用户身份头。
4. 使用同一受支持的服务访问 GET `/api/jobs/status`，附相同运行标志，确认返回的持久执行记录包含本次响应编号。
5. 对失败只报告内部执行状态，不尝试绕过权限。队列持久记录租约、尝试次数、延迟重试和最终失败；相同日期的任务和业务操作有防重复校验。最终失败由工作区所有者在工作流页面重新加入队列。

每小时运行时只将当日尚未加入的内部检查入队；每个工作区每天一条主检查。工作区关闭自动化后不再入队。维护只读模式拒绝执行写入。正常运行只更新数据，无需重新发布。
