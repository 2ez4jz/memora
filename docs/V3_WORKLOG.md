# MEMORA V3.0 更新工作记录

日期：2026-10-16。新增界面在 MEMORA；SCULPY 页面结构保持不变。

## 本次更新

1. 新增独立工作区和团队成员权限；员工只处理分配客户，只读成员不显示财务资料。
2. 将个人快照复制为规范化业务记录，保留原文、校验哈希和迁移清单；新业务工作区不导入演示数据。
3. 连接客户、活动、任务、报价、发票、人工收款与服务记录；客户详情显示关联业务。
4. 增加报价状态、接受后开票、部分收款、重复收据拦截、超额收款校验和服务状态转换。金额使用整数分。
5. 增加后台内部检查队列、租约、延迟重试、终止失败和每日摘要；服务状态变化生成内部提醒。
6. 增加按客户保存的私密图片、PDF 和录音附件，校验实际文件格式，支持中断重试与归档纠正。
7. 扩展 AI 查询和待确认操作，支持新客户、内部任务、客户修改、服务和报价草稿。所有写入重新验证权限和版本。
8. 增加团队共享及个人经营记忆；提出、确认、修改重审和撤销均可追溯。
9. 统一中文菜单、标题和常用按钮，增加手机功能菜单；保留英文功能切换。
10. 保留独立经营概览和默认图表，增加财务统计、团队记录及当前角色可见范围提示。
11. 增加私密备份导出、只读维护回退和隔离恢复验证。
12. 整理此前仓库更新说明与工作记录，使用自身功能描述。

## 测试发现与修复

- 旧客户未带版本字段时无法分配负责人：按已有数据版本规则兼容，并补充权限回归。
- 新菜单直接链接未进入对应页面：在完整导航注册后恢复地址路由。
- 选择团队记忆却保存为个人记忆：提交可见范围，并刷新服务器版本。
- 新增浏览器测试缺少绝对请求地址：修正测试请求配置；业务权限仍由实际后端验证。
- 只读角色仍可生成操作卡：在工具执行前拦截，新增数据库/工具测试和真实模型复验。
- 第五次执行崩溃后可能保留过期租约：超出重试上限转为明确终止状态，并测试恢复。

## 结果与验收范围

本地 56 项业务、数据库、权限、财务、安全和恢复测试通过。浏览器覆盖手机、平板、桌面，执行客户、报价、发票、部分收款、服务、附件、记忆和后台队列流程。最终提交对应的工作流结果以发布报告为准。

新增真实模型对照 50 组，每组两轮，旧版和本版共 200 次响应；修复后追加只读角色两轮复测。旧版通过 95/100 个定义的检查项；本版最终 100/100。自动检查验证工具、来源、金额和确认边界，不代表自然交流评分或真实同事验收。原始与修复前后回答保留在 `evaluations/v3-team/`。

真实麦克风、实体手机、实际同事首次登录和跨天使用仍需人工验收。对外发送、扣款和退款没有启用；系统不会因模型回答而执行这些操作。
