# MEMORA / SCULPY V3.0 首轮候选版交付报告

日期：2026-10-16。**本轮已实际开发、测试并准备发布；完整 V3.0 尚未完成，尚有明确的后续验收范围。**

## 本轮交付

按最新要求，SCULP 保留现有页面和发布会流程，新的 CRM 工作界面主要放在 MEMORA。

| 方向 | 本轮结果 | 状态与边界 |
|---|---|---|
| AI 交流和查询 | 中英文多轮、精确查询、财务比较、图表、客户时间线与重复检测工具 | 候选版已发布且实测通过；自然程度未伪造人工评分 |
| AI 操作 | 为指定客户生成跟进日期修改卡、内部任务确认卡；确认前不写入 | 已开发并真实模型验证；写入路径通过数据库/浏览器测试 |
| 客户管理 | 阶段看板、客户资料、自定义字段、活动时间线 | 已开发；手机采用短表单、列表分页和列内滚动 |
| 数据质量 | 邮箱/电话规范化、同名候选、CSV 模板、预览、确认导入 | 不自动合并、不覆盖旧客户；批量导入回滚尚未完成 |
| 任务和工作流 | 任务中心、每日摘要、到期跟进与长期未联系检查、防重复生成 | 部分完成：当前需确认运行，没有无人值守调度或持久失败重试队列 |
| 修改可靠性 | 服务端读取正式保存的个人工作区、版本校验、同请求重试、事务审计 | 已完成候选路径；普通保存不能重置服务端 CRM 状态 |
| SCULPY 后台 | 请求字节上限、工具参数二次校验、确认卡字段白名单 | 已完成，不改 SCULP 页面 |
| SCULPY 任务账本 | RLS、管理员校验、任务版本、请求重放、审计、停用回滚 | 已在隔离数据库及 PostgreSQL CI 验证；迁移未应用到生产 |
| 长期记忆 | 复用待确认→生效→修改重审→撤销及审计 | 存储生命周期测试通过；真实跨天使用仍待验收 |

## 实测结果

- SCULPY 本地完整测试：165 通过、0 失败；1 项多连接并发测试本地跳过，已在 GitHub PostgreSQL CI 中通过。既有财务、权限、订单、录音格式、图库、手机和 PWA 回归通过。
- MEMORA 本地测试：34 通过、0 失败。覆盖数据关联、金额、重复检测、CSV、任务、导入校验、自定义字段、跨用户隔离、版本冲突、请求重试及审计事务失败回滚。
- 浏览器 CI：390 / 768 / 1440 宽度，实际操作任务、工作流、客户资料与时间线，检查横向溢出。截图已内部复查；没有把模拟浏览器说成实体 iPhone 验收。
- 真实模型：50 组、每组 2 轮，旧版/候选版对照共 200 次响应；修复后重跑 MEMORA 25 组 50 次；另有 3 次真实录入回归，共 253 次响应。两套数据各为现有 300 条虚构记录。
- 旧版通过 96/100 项定义的合同检查；最终候选版通过 100/100。这里检查的是工具调用、准确金额、确认边界等，**不是“整体能力 100%”“自然度 100 分”或生产权限全部通过**。
- 有效记忆模型用例使用已确认的上下文测试记录；真实持久存储生命周期另由数据库测试覆盖。没有声称等了一天完成跨天验收。

完整输入、实际输出、预期检查、耗时及修复前回答：`evaluations/v3-50-groups-final.json`；逐组索引：`evaluations/v3/README.md`。

## 实测发现与修复

| 发现 | 修复 | 复验 |
|---|---|---|
| 第一轮生成了确认卡，第二轮却否认生成过 | 历史保留确认卡的真实待确认状态 | M12/M13 真实多轮重跑通过；原回答保留 |
| 录入提示把“下周”猜成七天后 | 未定星期几则留空并提示选择具体日期 | 模糊下周、明天、计划试驾 3 次真实录入通过 |
| 普通保存后客户端版本号落后 | 返回服务端客户版本并更新本机状态 | 专项存储测试通过 |
| 大量任务和商机让手机页面过长 | 任务分页、阶段筛选、看板内部滚动 | 浏览器 CI 及截图复查通过 |
| 模型输出可能夹带 saved 等界面标志 | SCULPY 仅接受规定的卡片字段 | 专项工具边界测试通过 |

## 安全、财务与数据

没有读取真实客户详情，没有删除、覆盖或导入真实订单。审计时生产库客户和订单数量均为 0。虚构数据只用于 Demo/隔离评测；SCULPY 正式统计仍由原授权 RPC 提供，不把 Demo 写入其中。密钥仍留在现有服务端，没有复制到前端或报告。

SCULPY 全部公开业务表已有 RLS。Supabase 顾问仍报告既有 SECURITY DEFINER RPC 可由已登录角色调用的提示，以及泄露密码保护未开启；本轮用角色检查和私有函数封装验证了实际访问边界，未把“没有顾问提示”当成通过标准，也未擅自开通可能涉及账户设置的服务。参考：
- https://supabase.com/docs/guides/database/database-linter?lint=0029_authenticated_security_definer_function_executable
- https://supabase.com/docs/guides/auth/password-security#password-strength-and-leaked-password-protection

成交收入、到账、车辆毛利、净利润保持分开。没有成本/退款流水时不计算净利润；没有有效账单、到期日及付款记录时，不把差额当成逾期欠款。SCULPY 新任务迁移只增加表和函数，不修改订单金额；停用回滚会撤销新 RPC 权限并保留任务和审计，已在隔离数据库执行验证。

临时真实模型评测函数已关闭：410 响应并重新开启 JWT 验证，不再调用模型或访问数据库。
