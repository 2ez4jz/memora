# MEMORA · SCULP 功能移植

日期：2026-10-16（Toronto）。基线：MEMORA GitHub main（2026-10-09），参考 SCULP `026ce4e`。

## 实现

- 默认中文，保留 English 切换及持久语言偏好。沿用现有 Sites 项目与服务器 API 密钥，域名及邮箱记录不变。
- Responses API 沿用工具调用框架，默认模型改为 `gpt-6-sol`；自然聊天、多轮上下文、商业/财务/获客按需指导。没有另接 Agents SDK，避免引入与现有 Worker 不同的运行框架。
- 改为近12个月300条虚构客户记录及关联沟通和成交。历史成交车辆与18辆当前库存分开；毛利锁定该笔购入成本。旧浏览器保存的数据保留，重置后才使用新种子数据。
- Dashboard 独立于聊天：起止日期、快捷日期、每月成交收入、客户来源、客户当前阶段；当前待跟进与历史时间段明确分开。
- 客户六位可搜索编号，点击打开档案；CSV 导出期间成交。号码避开4，但无需复制婚礼服务分类；前缀61表示客户档案。
- 手机聊天布局使用独立滚动区及输入栏；所有页面紧凑布局，小屏客户表为卡片。Markdown 表格与按需问答图，均价不合计、不生成饼图。
- 复用 SCULP 已修复的音频容器识别：Safari MP4字节、MIME、扩展名一致。聊天和记录均可录音，服务器转写后先编辑再发送/提取；最多90秒/10MB。
- D1持久保存用户工作区与对话，同一Sites账户可跨设备读取，版本冲突拒绝覆盖。已有本地资料仍保留。
- 经营记忆：提出、确认、修改后重新审核、撤销、版本检查和审计；仅服务端检索的已确认记忆进入回答。按Sites用户隔离，缺身份拒绝存储访问。

## 业务口径

成交收入不是现金到账；车辆毛利只扣购入成本，不是净利润。没有退款、整备、投放花费、工时或完整同批线索观察记录，不能计算净收款、净利润、CAC、ROI或真实转化率。客户预算是偏好信号，不等于已验证消费能力。没有复制SCULPY专属老板语气。

## 验证与边界

本地18项测试通过：日期边界、成交/购入成本重算、均价与样本、数据关联、D1 SQL迁移及隔离/版本冲突、记忆全生命周期/审计、MP4识别、HTTP边界、模拟模型工具循环与语言指令、六个页面执行和嵌入脚本编译。

未安装可用的control-browser技能，依Sites要求跳过浏览器视觉验收，没有声称完成真机或截图验收。真实手机麦克风、真实跨天/多设备、多人团队权限仍需人工验收。当前持久数据按用户隔离，尚非团队共享CRM；Github Pages离线演示不具备Sites身份和后端，真实AI入口为原Sites项目。

初版已部署成功；已有线上API返回gpt-6-sol。初版30组多轮与最终跨期计算/记忆措辞的针对性复验分别留档，不合并成同一构建。真实用户身份与真机录音仍待人工验收。
